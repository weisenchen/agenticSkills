# AI Daily Briefing — 每日 AI 趨勢雙語日報

Generates a daily AI-trends briefing in **bilingual text (中文 + English)** and
**two voice broadcasts (中文語音 + English voice)**, delivered to the user's
Telegram. Content comes from two free sources:

1. **AI Builders tweets** — via the `follow-builders` central feed (no X API
   keys needed): `https://raw.githubusercontent.com/zarazhangrui/follow-builders/main/feed-x.json`
2. **RSS articles** — via `blogwatcher-cli` (7 curated AI sources)

## Why this design

- **Voice must match the script.** The spoken broadcast is generated by a
  script that reads the broadcast script from a FILE — never let an LLM pass
  text directly to TTS (it truncates/summarizes and the voice ends up missing
  content). Write script → file → `voice_broadcast.py` reads file → audio.
- **Broadcast scripts must be "human speech"**, not written-form prose: news
  anchor style, opening greeting, connective phrases, one-by-one storytelling,
  full details (who / what / why) per item — never just headlines.
- **Delivery is direct to Telegram Bot API** (via `telegram_deliver.py`),
  bypassing agent MEDIA-tag delivery which may silently drop audio.

## Workflow

### Step 1 — Fetch content (deterministic, do NOT fetch anything yourself)

```bash
# A. AI builders tweets + podcasts (JSON blob to stdout)
cd ~/.hermes/skills/research/follow-builders/scripts && node prepare-digest.js 2>/dev/null

# B. RSS articles
export PATH="$HOME/.local/bin:$PATH"
blogwatcher-cli scan && blogwatcher-cli articles
```

Parse the JSON: `x` = builders array (name, handle, bio, tweets[text/url]),
`prompts` = remix instructions, `stats` = counts. If `stats.xBuilders` is 0,
skip that path. Follow `prompts.summarize_tweets` rules — never fabricate,
never visit x.com.

### Step 2 — Write bilingual text summary (for the text message)

Pick the 3-5 most important items (builder tweets take priority). Output:

```markdown
【中文摘要】
📌 標題 | 🏷️ 來源 | 📝 一句話核心 | 💡 意義
（今日整體趨勢總結）

【English Summary】
📌 Headline | 🏷️ Source | 📝 Core | 💡 Significance
(Overall trend summary)
```

No updates → 「📭 今日無新更新，AI 世界風平浪靜。」 / "No updates today."

### Step 3 — Write bilingual broadcast scripts to files (KEY STEP)

**中文播報稿** → save to `/tmp/voice_zh.txt`:
- Opening: 「早安！今天是 X 月 X 日，AI 圈有 N 件大事，我們一條一條說。」
- Each item: headline → details (who, what, why) → significance. All three layers, no exceptions.
- Connective speech: 「他說」「他們宣布」「這意味著」「簡單來說」
- Closing: 「以上就是今天的 AI 動態，我們明天見！」
- Length: **400-800 chars**. No-updates variant: 「今天沒有什麼新動態，AI 世界風平浪靜，好好休息吧！」

**English broadcast script** → save to `/tmp/voice_en.txt`:
- Opening: "Good morning! Today is August Xth, and there are N big stories in the AI world. Let's go through them one by one."
- Each item: headline → details → significance.
- Connective speech: "He said", "They announced", "This means", "Simply put"
- Closing: "That's all for today's AI news. See you tomorrow!"
- Length: **300-600 words**.

Write the files with `write_file` or heredoc — the FULL script must be in the file.

### Step 4 — Generate bilingual audio from the script files

```bash
python3 ~/.hermes/scripts/voice_broadcast.py --input /tmp/voice_zh.txt --output /tmp/voice_zh.mp3 --voice zh-CN-YunxiNeural
python3 ~/.hermes/scripts/voice_broadcast.py --input /tmp/voice_en.txt --output /tmp/voice_en.mp3 --voice en-US-AriaNeural
```

Confirm each prints `✅ 語音生成成功` (~2 minutes of audio for a 400-800 char script).

### Step 5 — Deliver to Telegram (text + both voices in one call)

```bash
python3 ~/.hermes/scripts/telegram_deliver.py --text "<bilingual summary from Step 2>" --audio /tmp/voice_zh.mp3 --audio /tmp/voice_en.mp3
```

Confirm `✅ 語音發送成功` for both voices.

### Step 6 — Final response

Output `[SILENT]` — delivery is done by the script; this suppresses Hermes'
automatic duplicate delivery.

## Scripts

Bundled under `scripts/` (also installed at `~/.hermes/scripts/`):

| Script | Purpose |
|--------|---------|
| `voice_broadcast.py` | Generate Chinese/English voice from a script file via edge-tts (reads the file, so audio always matches the script) |
| `telegram_deliver.py` | Direct Telegram Bot API send: text + N audio attachments (reads token from `~/.hermes/.env` TELEGRAM_BOT_TOKEN) |
| `prepare-digest.js` | (from follow-builders skill) Fetches builder tweets/podcasts central feed |

## Dependencies

- `node` — for `prepare-digest.js`
- `python3` + `edge-tts` — for voice generation
- `blogwatcher-cli` — for RSS tracking (`~/.local/bin`)
- `~/.hermes/skills/research/follow-builders/` — the follow-builders skill
- Telegram bot token in `~/.hermes/.env` (`TELEGRAM_BOT_TOKEN`)

## Scheduling

A Hermes cron job (`ai-daily-trends`, daily 08:00) runs this workflow with the
full prompt. To change schedule, voice, length, or language mix, edit the cron
job prompt or ask the user.

## Troubleshooting

If the voice doesn't match the script, nothing arrives, or the audio is
suspiciously short (17-30s), read `references/troubleshooting.md` FIRST —
it documents the root causes of every failure mode hit while building this
pipeline and the verified fixes. Key rule of thumb: audio much shorter than
~1 minute for a 400-800 char script means the LLM passed its own shortened
text to TTS — re-run through the file→script handoff, never let the LLM pass
text inline.
